## What this is

A single-page, zero-dependency portfolio that connects two sides of the same practice:

- **Engineering systems** — FEA, CFD, topology optimization, thermal management, robotics, autonomy, and AI inspection.
- **Live experiences** — cinematic, scroll-driven web work for travel, fashion, and climate-tech.

The page is designed as a fast, editorial hub: large typography, real screenshots, scroll reveals, and direct links to every live site and repository.

## Highlights

- **Editorial layout** — oversized type, generous spacing, and a dark cinematic palette.
- **Live project stack** — overlapping, tilted previews of the real sites.
- **Hover + scroll motion** — subtle reveal and image-scale effects, with reduced-motion support.
- **Responsive** — a two-column desktop grid that becomes a clean single column on mobile.
- **SEO-ready** — descriptive title, meta description, Open Graph, Twitter card, and SVG favicon.
- **No dependencies** — one HTML file, three screenshots, and the font CDN.
